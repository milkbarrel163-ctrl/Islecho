# Islecho

"Islecho" is intelligent agent based on JUCE and C++. It creates an evolving world that audiences can listen to and influence. Fish, flowers, fireflies, waves, and wind generate distinct sounds as the landscape changes, producing a soundscape that does not repeat exactly. Rhythmic taps can bring the living elements into a short ensemble of clear bell tones and soft, airy textures. The work aims to offer a calming experience while exploring how people and an ecosystem can create music together. And form a balance between human and nature.
